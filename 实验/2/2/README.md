## 实现功能

### 基本要求（4 个 TODO）

1. **TODO1 — 墨西哥帽网格建模**：按课件 lec4《几何造型技术》p.39-40 的公式，先把 `(x, z)` 平面等距划分为 11×11 个网格点并规约到 `[-1,1]`，再由 `r = √(x²+z²)` 求高程 `y = sin(πr)/(πr)`（`r=0` 处 `y=1`）；每个方格取 4 个顶点按逆时针顺序展开为两个三角形写入顶点数组。颜色按高程做蓝→红渐变（`smoothstep` 缓入缓出，避免色带），再乘上由高程梯度**解析求得**的顶点法线所做的漫反射系数，使帽顶隆起与帽檐翻卷的起伏更清晰可辨。
2. **TODO2 — 模型变换矩阵 M**：由 `modelTrans`（平移）、`modelRot`（旋转）、`modelScale`（缩放）三个累积量按 `M = T·R·S` 合成。
3. **TODO3 — 观察变换矩阵 V**：相机在半径 `camRadius`（默认 `4.0`，滚轮可在 `1.5~12` 之间缩放）的球面上运动，`eye` 由极坐标 `(theta, phi)` 参数化，`up` 由球坐标框架解析给出，最后调用 `MVnew.js` 的 `lookAt(eye, at, up)`。
4. **TODO4 — 投影矩阵 P**：由 `isOrth` 标志位切换 `ortho(...)` 与 `perspective(...)`，`aspect` 随画布实际纵横比传入；视见体参数保证把场景景物全部包含在内；透视投影的视野角 `fov`（默认 `60°`）由 M/N 键或侧栏滑块实时调整。

### 附加功能

- **鼠标拖动的虚拟跟踪球**：按住鼠标左键拖动时，把鼠标起点与终点投影到单位半球面，绕两点的叉乘轴转动其夹角，从而使物体绕任意轴转动；
- **平移/旋转/缩放三种基本变换的累积变换**：方向键（物体平移）+ 鼠标左键拖动（任意轴旋转）+ Z/C（整体缩放）互不覆盖，可任意叠加，最终合成为 `M = T·R·S`；空格键一键复位。
- **重做的应用式界面**：顶部工具栏（模型 + 视图预设 + 投影切换 + 复位）、中央视口、右侧设置面板（模型 / 相机 / 物体变换 / 显示 / 操作说明）、底部状态栏，配色沿用实验一的浅色视觉语言；
- **重新打磨的场景坐标系**：三色轴 + 圆锥箭头 + 正向实线/负向虚线 + 主次网格 + 距离淡出 + 角落朝向 gizmo + HTML 矢量轴标签（详见下文"界面布局"与"场景坐标系"）；
- **顶点级漫反射着色**：把一盏方向光在生成顶点数据时就烘焙进顶点颜色，使方块六个面明暗分明、球体有平滑的体积明暗过渡（并替换掉框架原有的"每三角形青/品红/绿"拼色噪点）、帽面的隆起与翻卷更立体。**不改着色器**，渲染管线与 alpha 淡出逻辑完全不受影响。
- **更直觉的鼠标相机操作**：右键拖动旋转相机、滚轮缩放相机距离、7 个视图预设一键跳转。

## 技术要点

### 墨西哥帽高程函数（lec4 p.39）

平面坐标 `x = j·2/(nColumns-1)-1`、`z = i·2/(nRows-1)-1`，高程：

```
y = sin(πr)/(πr),  r = √(x²+z²) ≠ 0
y = 1,            r = 0
```

每个方格以 `A(i,j) → D(i+1,j) → C(i+1,j+1) → B(i,j+1)` 的逆时针顺序取 4 个顶点，展开为两个三角形 `A,D,C` 与 `A,C,B`。

### 相机球面漫游与 up 向量（lec6 p.45-49）

```
eye = r·( sinφ·sinθ , cosφ , sinφ·cosθ )
up  = ( -cosφ·sinθ , sinφ , -cosφ·cosθ )
```

其中 `θ` 为绕 Y 轴的方位角（A/D 键改变），`φ` 为相对 +Y 轴的仰角（W/S 键改变）。该 `up` 向量恒为单位向量且与 `eye` 恒正交，因此相机正对 ±Y 极点时也不会与观察方向共线退化。默认 `theta=45°`、`phi=54.7356°`、`radius=4.0`，即 **等轴测视角**：`φ=arctan(√2)`、`eye=(2.31,2.31,2.31)`，三根正向轴在屏幕上等长且互成 120°，+Y 竖直向上、+X 指向右下、+Z 指向左下，能同时看清三个坐标轴。

### 变换矩阵的串联与传递

顶点着色器中按课件 lec6 p.53：`gl_Position = P·V·M·vPosition`；其中绘制坐标轴/网格/gizmo 时不做 M 变换，用 `u_Flag` 区分（`P·V`）。`MVnew.js` 的 `flatten()` 会把行主序矩阵转置为 GLSL 要求的列主序后上传。

### 深度缓存

每帧清屏同时清除颜色与深度缓存（`COLOR_BUFFER_BIT | DEPTH_BUFFER_BIT`），否则旋转/缩放后残留的深度值会导致物体内部遮挡关系出错。

## 场景坐标系

参考自建 RayTracer 项目（Three.js）的网格 / 轴 gizmo 做法，并针对其相对 Unity 场景视图的不足做了 7 项优化：

| # | RayTracer 的做法 | 本次优化 |
| --- | --- | --- |
| 1 | 网格线单一密度、纯灰，远处密集如噪点 | **主次双密度网格**（次格 0.25、主线 1.0）+ 按到原点距离**逐线 alpha 淡出**（`a = clamp(1-\|t\|/3.2, 0.10, 1)`，主线 `rgb(0.36,0.40,0.47)` 与次线 `rgb(0.72,0.76,0.81)` 拉开层次），配合 `GL_BLEND` 实现，无需改着色器 |
| 2 | 主场景没有贯穿场景的彩色坐标轴 | **三色轴贯穿原点**：X 红 `#e13b3b`、Y 绿 `#3ab54a`、Z 蓝 `#3a6ee1`；正向为实线 + **圆锥三角扇箭头**（24 段，轮廓圆润），负向取同色 55% 亮度并改为**虚线**（dash 0.12 / gap 0.07），正负半轴一眼可分；网格的中心两条线仍保留、由轴覆盖绘制，既避免中心空洞又消除同深度双线 |
| 3 | gizmo 标签用 `Sprite` 贴图，缩放后模糊 | 轴标签改用 **HTML 覆盖层**（矢量清晰）：每帧把世界点 `(±L,0,0)/(0,±L,0)/(0,0,±L)` 经 `P·V` 投影为像素坐标写入 `style.left/top`；`clip.w<=0` 或位于相机平面之后时隐藏 |
| 4 | gizmo 只作被动指示、无视图预设 | 新增 **7 个视图预设**（前 / 后 / 左 / 右 / 上 / 下 / 等轴测，工具栏一键切换并按当前 θ、φ 自动高亮） |
| 5 | 网格几何随相机距离反复重建（GC 抖动） | 网格**一次性生成静态顶点**，不做重建 |
| 6 | 只有透视投影 | 正交 / 透视**显式可切**（`P` 键、工具栏按钮、`isOrth` 标志位） |
| 7 | 相机距离由 OrbitControls 的固定区间硬性决定 | 滚轮精细控制相机距离 `camRadius ∈ [1.5, 12]`，`at` 恒为原点，正交投影下竖向视野固定 ±3.2（横向随纵横比），保证 ±3 网格在俯视图下不被裁切 |

**渲染顺序（多 pass）**：①清屏 → ②物体（`TRIANGLES`，写深度）→ ③地面网格、再画三色轴（`depthMask(false)`，`depthFunc(LEQUAL)`，被物体正确遮挡且轴覆盖网格中心线）→ ④角落 gizmo 用 `SCISSOR_TEST` 圈出右上角 96×96 小方区、只清该区深度、改为"只旋转不平移"的视图矩阵与 `ortho(±0.72)` 绘制，随后恢复 viewport。

**角落朝向 gizmo**：绘制在 `(W-110, H-110, 96, 96)` 的小视口内（与页面右上角 `#gizFrame` 边框同位置同尺寸），相机方向随主相机联动、大小恒定，用于快速判断当前朝向；可由侧栏"显示"面板单独关闭。

**坐标轴与网格的层次**：网格 half=3.0 覆盖 ±3 范围，坐标轴只到 ±2.0，中心两条网格线仍绘制并被轴覆盖，因此不存在"轴外空白"。物体段顶点数随模型变化（方块 36 / 球 49152 / 墨西哥帽 600），固定段恒为 **坐标轴 288 + 网格 100 + gizmo 150 = 538** 个顶点；其中坐标轴段内是"线段 72 顶点（正向 3 条实线 + 负向 3 条各 11 段虚线）在前、圆锥 216 顶点在后"，gizmo 段内是"线段 6 顶点在前、圆锥 144 顶点在后"——**每个段内都是先线段后三角形**，因为一段内混有两种图元时无法用一次 `drawArrays` 画完。

## 顶点明暗（Lambert 漫反射，烘焙进顶点色）

三种模型都采用同一套明暗模型，公式：`k = min(1, ambient + diffuse · max(0, n·l))`，顶点色 = 基色 × k（`ambient = 0.38`、`diffuse = 0.72`，方向光 `l` 取世界坐标下的右上偏前上方 `(0.600, 0.720, 0.350)`）。

| 模型 | 法线来源 | 效果 |
| --- | --- | --- |
| 方块 | 六个面的外法线常量（按 `quad()` 的首参映射） | 顶面/右面亮、底面/左面/后面暗，六面明暗分明 |
| 球体 | 球面顶点自身的单位向量（即归一化后的位置） | 单一色相的平滑体积过渡，取代框架原有的青/品红/绿拼色噪点 |
| 墨西哥帽 | 由高程函数解析求导 `dy/dr = (πr·cos πr − sin πr)/(π r²)` 得到曲面法线 | 帽顶隆起与帽檐翻卷的明暗交界清晰 |

因为色相（基色之比）在调制后保持不变，所以对颜色直观判断没有干扰；又因为明暗是**在顶点数据阶段烘焙**的，着色器、渲染管线、坐标轴/网格的 alpha 淡出逻辑全部不用改动。
