## 实现功能

### 基本要求（4 个 TODO）

1. **TODO1 — 墨西哥帽网格建模**：按课件 lec4《几何造型技术》p.39-40 的公式，先把 `(x, z)` 平面等距划分为 11×11 个网格点并规约到 `[-1,1]`，再由 `r = √(x²+z²)` 求高程 `y = sin(πr)/(πr)`（`r=0` 处 `y=1`）；每个方格取 4 个顶点按逆时针顺序展开为两个三角形写入顶点数组，颜色按高程做蓝→红渐变。
2. **TODO2 — 模型变换矩阵 M**：由 `modelTrans`（平移）、`modelRot`（旋转）、`modelScale`（缩放）三个累积量按 `M = T·R·S` 合成。
3. **TODO3 — 观察变换矩阵 V**：相机在半径 `radius = 2.0` 的球面上运动，`eye` 由极坐标 `(theta, phi)` 参数化，`up` 由球坐标框架解析给出，最后调用 `MVnew.js` 的 `lookAt(eye, at, up)`。
4. **TODO4 — 投影矩阵 P**：由 `isOrth` 标志位切换 `ortho(...)` 与 `perspective(...)`，视见体参数保证把场景景物全部包含在内；透视投影的俯仰角 `fov` 由 M/N 键实时调整。

### 附加功能

- **鼠标拖动的虚拟跟踪球**：按住鼠标拖动时，把鼠标起点与终点投影到单位半球面，绕两点的叉乘轴转动其夹角，从而使物体绕任意轴转动；
- **平移/旋转/缩放三种基本变换的累积变换**：方向键（物体平移）+ 鼠标拖动（任意轴旋转）+ Z/C（整体缩放）互不覆盖，可任意叠加，最终合成为 `M = T·R·S`；空格键一键复位。

### 交互总览

| 操作 | 功能 |
| --- | --- |
| 鼠标拖动画布 | 物体绕任意轴旋转（虚拟跟踪球） |
| 方向键 ← → ↑ ↓ | 物体累积平移 |
| Z / C | 物体整体放大 / 缩小 |

## 技术要点

### 墨西哥帽高程函数（lec4 p.39）

平面坐标 `x = j·2/(nColumns-1)-1`、`z = i·2/(nRows-1)-1`，高程：

```
y = sin(πr)/(πr),  r = √(x²+z²) ≠ 0
y = 1,            r = 0
```

每个方格以 `A(i,j) → D(i+1,j) → C(i+1,j+1) → B(i,j+1)` 的逆时针顺序取 4 个顶点，展开为两个三角形 `A,D,C` 与 `A,C,B`。

### 相机球面漫游与 up 向量（lec6 p.45-49）

```
eye = r·( sinφ·sinθ , cosφ , sinφ·cosθ )
up  = ( -cosφ·sinθ , sinφ , -cosφ·cosθ )
```

其中 `θ` 为绕 Y 轴的方位角（A/D 键改变），`φ` 为相对 +Y 轴的仰角（W/S 键改变）。该 `up` 向量恒为单位向量且与 `eye` 恒正交，因此相机正对 ±Y 极点时也不会与观察方向共线退化。默认 `theta=0`、`phi=90` 时 `eye=(0,0,2)`、`up=(0,1,0)`（与框架初始值一致）。

### 变换矩阵的串联与传递

顶点着色器中按课件 lec6 p.53：`gl_Position = P·V·M·vPosition`；其中绘制坐标轴时不做 M 变换，用 `u_Flag` 区分（`P·V`）。`MVnew.js` 的 `flatten()` 会把行主序矩阵转置为 GLSL 要求的列主序后上传。

### 深度缓存

每帧清屏同时清除颜色与深度缓存（`COLOR_BUFFER_BIT | DEPTH_BUFFER_BIT`），否则旋转/缩放后残留的深度值会导致物体内部遮挡关系出错。
