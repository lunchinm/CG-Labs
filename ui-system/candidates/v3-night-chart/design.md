# V3 夜航图（Night Chart）

> 候选版本，供挑选。正式规范在选定后提升为 `ui-system/design.md`。

## 1. 定位

把渲染器当成一张夜航图：坐标、档位、信号灯、图例、等高线。适合黄昏湖畔的冷色时段，也适合实验 1、2 中“空间关系”较强的演示——相机、光源、投影都可以画成坐标与方位。

关键词：深海、海图青、信号橙、等高线、坐标、图例。

## 2. 反面清单

- 卡片网格、圆角容器、胶囊标签、彩色徽章。
- 渐变、毛玻璃、发光、投影、噪点纹理。
- emoji、通用图标库、雷达扫描动画、装饰性网格。
- 裸滑杆、裸下拉框、无单位读数。
- 把“航海”做成木纹、羊皮纸或复古地图贴图。

## 3. Token

### 3.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ui-bg` | `#0a1420` | 页面底色 |
| `--ui-bar` | `#0c1826` | 顶栏、状态账本 |
| `--ui-surface` | `#0f1d2b` | 仪表架、浮层 |
| `--ui-surface-2` | `#142434` | 悬停底 |
| `--ui-surface-3` | `#182b3c` | 二级浮层 |
| `--ui-ink` | `#dce7ec` | 主文字 |
| `--ui-muted` | `#8aa3b2` | 次级文字 |
| `--ui-faint` | `#5b7484` | 注释 |
| `--ui-line` | `rgba(126,166,184,.18)` | 海图网格线 |
| `--ui-line-strong` | `rgba(126,166,184,.36)` | 焦点边框 |
| `--ui-accent` | `#e4572e` | 信号橙：选中、游标、警告 |
| `--ui-cool` | `#7ea6b8` | 海图青：标签、坐标、图例 |

信号橙只用于“当前档位/当前焦点”，海图青用于“结构性信息”。两者不互换。

### 3.2 字体

| 角色 | 字体 | 字号 | 用法 |
| --- | --- | --- | --- |
| 标题 | IBM Plex Sans 600（wdth 75–100） | 11px | 顶栏、抽屉、浮层标题 |
| 标签 | IBM Plex Mono（中文回退 Noto Sans SC） | 9px | 字段标签、账本标签 |
| 读数 | IBM Plex Mono | 11px | 数值、单位、键位 |
| 正文 | IBM Plex Sans / Noto Sans SC | 13px | 命令索引、说明 |

字体全部本地打包，不使用系统默认栈；窄体效果来自 IBM Plex Sans 的 `wdth` 可变轴。

标题一律大写 + 字距 `.2em–.24em`；标签 `.16em`；读数 `.02em`。

### 3.3 底纹

仪表架使用一张 200×200 的 SVG 等高线，`stroke` 为海图青、`opacity: .09`，通过 `background-repeat` 平铺。要求：

- 只用 1px 以下的 SVG 线条，不用渐变、噪点或位图。
- 底纹不得影响文字对比度；文字区域仍以实底 `--ui-surface` 为主。
- 命令索引浮层不使用底纹，避免干扰搜索。

## 4. 排版

### 4.1 字段行

与 V1 相同的三列网格（58 / 1fr / 46），但标签改为 9px 等宽、字距 `.16em`，形成“坐标标签”的气质。长标签同样上下排。

### 4.2 抽屉

- 收起：海图线分隔，编号海图青。
- 展开：左侧 2px 信号橙条 + 编号变橙；标题不变色。
- 抽屉头 38px，与 V1 一致，方便横向比较。

## 5. 组件解剖

### 5.1 刻度滑杆 `gauge`

- 轨道与填充 1px；填充信号橙、透明度 .7。
- 滑块是 1×18px 竖线，中间叠加 11px 横线，形成十字准星。
- 刻度 11 根；每 5 根加高到 6px 并改用海图青。
- 交互与前两版一致。

### 5.2 档位 `bank`

- 连体单元格，外框与竖线使用强海图线；底色比面板更深一档。
- 选中：信号橙文字 + 2px 底部橙线；不加填充、不加圆角。
- 六个 `PASS` 档位使用紧凑字号（9px、无字距），保证 316px 面板内一行放下。

### 5.3 机械开关 `key`

- 底色为半透明深海底（纯色透明度，不是毛玻璃）。
- LED 是 5×5px 旋转 45° 的菱形；开启时填充信号橙。
- 开启态整行加一层 8% 信号橙底，用于快速扫读，不加发光。

### 5.4 状态账本

- 标签海图青、字距 `.18em`；读数纸白。
- 五等分；格间 1px 海图线。
- 不使用图标或 LED，避免与面板开关混淆。

### 5.5 命令索引与键位账本

- 标题窄体大写；分组名海图青。
- 选中行底色用 7% 海图青，并保留 `base.css` 的 2px 信号橙左条。
- 快捷键列信号橙；搜索框保持等宽。

### 5.6 边轨与画布把手

- 边轨背景与仪表架一致，边框用强海图线。
- 悬停编号变信号橙；`TOP` / `HUD` 把手沿用同一套边框。

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| idle | 海图线 + 海图青标签 |
| hover | 6% 海图青底；不改变文字色 |
| focus-visible | 1px 信号橙外环 |
| active | 信号橙文字 / 菱形灯 / 底部 2px 线 |
| disabled | 透明度 .38 |
| echo | 行底色 `surface-2` + 左侧 2px 橙条，600ms |

布局三态与 V1、V2 完全一致；差异只在 token 与控件形态，因此三版可以直接切换比较。

## 7. 可访问性

- 等高线底纹透明度必须 ≤ .1，且不铺在文字背后形成高频干扰。
- 信号橙与海图青的对比度分别验证：橙 `#e4572e` on `#0f1d2b` ≈ 4.6:1；青 `#7ea6b8` on `#0f1d2b` ≈ 6.4:1。
- 菱形 LED 只是辅助，状态同时由 `ON/OFF` 文本表达。
- 滑杆、档位、开关的 ARIA 与 V1 相同；`prefers-reduced-motion` 下关闭过渡。

## 8. 扩展规则

- 新字段沿用三列网格；新分组沿用编号 + 窄体大写标题。
- 需要“坐标读数”时使用等宽读数，不用图形化仪表盘。
- 需要“图例”时用一行文字 + 色块（2×8px），不做圆形徽章。
- 新底纹只能加 SVG 线条图案；禁止渐变、位图和噪点。
- 换主题只改 `@layer tokens`；底纹可在 `.ui-rack` 一处替换或移除。

## 9. 复用到实验 1、2

- 实验 1：把 `03 EFFECTS` 换成 `03 PROJECTION`，档位改为 `ORTHO / PERSP / FRUSTUM`，与“航线图”的档位语义一致。
- 实验 2：抽屉改为 `01 MODEL / 02 VIEW / 03 PROJECTION / 04 LIGHT`，账本显示相机方位角、俯仰角、距离，像导航读数。
- 若实验 1、2 需要更亮的场景，只提高 `--ui-bg/surface` 明度，保留信号橙与海图青的关系。

## 10. 验收清单

- [ ] 等高线底纹是纯 SVG 线条，透明度 ≤ .1，文字区域可读。
- [ ] 信号橙只用于当前档位/焦点，海图青只用于结构信息。
- [ ] `PASS` 六个档位在 316px 面板内单行放下，不换行、不截断。
- [ ] 滑杆十字准星在拖动时始终对齐轨道。
- [ ] 没有卡片、胶囊、渐变、投影、毛玻璃、emoji。
- [ ] 三态收起、`Ctrl+K`、`?`、`P`、`F`、`Space` 均正常。
- [ ] 1280px 与 900px 下无重叠、无横向滚动。
