# V1 暮色测量台（Dusk Survey）

> 候选版本，供挑选。正式规范在选定后提升为 `ui-system/design.md`。

## 1. 定位

把渲染参数当成测绘仪器来读：编号、刻度、读数、账本。适合黄昏湖畔场景，也适合实验 1、2 的几何与变换演示——它们同样需要“看清数值、看清状态”，而不需要一张后台管理卡片。

关键词：石墨、琥珀、发丝线、刻度、等宽读数、非对称。

## 2. 反面清单

以下做法在本版本中一律不出现：

- 2×2 / 3×2 等分卡片；选项卡做成卡片网格。
- 圆角容器承载整块内容、胶囊标签、彩色底徽章、推荐角标。
- 渐变、毛玻璃、发光、投影、噪点纹理。
- emoji 图标、通用图标库、`✨ 智能` 一类文案。
- 裸滑杆、裸下拉框：每个控件必须带单位、范围或读数。
- 居中大标题 + 副标题的落地页结构。

## 3. Token

### 3.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ui-bg` | `#0e1319` | 页面底色 |
| `--ui-bar` | `#101720` | 顶栏、状态账本、画布把手 |
| `--ui-surface` | `#151c24` | 仪表架、浮层 |
| `--ui-surface-2` | `#1a222c` | 悬停、选中底、档位底 |
| `--ui-surface-3` | `#202a35` | 二级浮层、折叠区 |
| `--ui-ink` | `#e9e3d8` | 主文字、读数 |
| `--ui-muted` | `#94a1ae` | 标签、说明 |
| `--ui-faint` | `#5f6b77` | 注释、占位 |
| `--ui-line` | `rgba(233,227,216,.14)` | 发丝线 |
| `--ui-line-strong` | `rgba(233,227,216,.28)` | 焦点边框、浮层边框 |
| `--ui-accent` | `#e8a45c` | 唯一强调色：选中、焦点、滑块 |
| `--ui-cool` | `#7fa6b8` | 状态信息：编号、账本标签 |
| `--ui-focus` | `#e8a45c` | 键盘焦点环 |

规则：一屏只允许一个强调色。冷蓝只用于“状态/编号”，不用于可点击焦点；可点击焦点永远是琥珀。

### 3.2 字体与字号角色

| 角色 | Token | 字体 | 字号 | 用法 |
| --- | --- | --- | --- | --- |
| 图纸标题 | `--ui-text-caption` 11px | `--ui-font-display`（IBM Plex Sans 600） | 11px | 顶栏名、抽屉标题、浮层标题 |
| 微型大写标签 | `--ui-text-micro` 10px | `--ui-font-body`（IBM Plex Sans / Noto Sans SC） | 10px | 字段标签、账本标签、命令分组 |
| 等宽读数 | `--ui-text-caption` 11px | `--ui-font-mono`（IBM Plex Mono） | 11px | 数值、单位、键位、坐标 |
| 正文 | `--ui-text-body` 13px | `--ui-font-body`（IBM Plex Sans / Noto Sans SC） | 13px | 命令索引行、说明 |

字体全部本地打包，不使用系统默认栈；中文使用 Noto Sans SC 子集。

标题一律 `letter-spacing: .16em–.2em`；标签 `.1em–.14em`；读数 `0–.02em`。不允许全篇 13px。

### 3.3 间距与尺寸

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ui-topbar-h` | 44px | 顶栏 |
| `--ui-ledge-h` | 34px | 状态账本 |
| `--ui-rack-w` | 316px | 仪表架 |
| `--ui-rail-w` | 24px | 收起后的边轨 |
| `--ui-pad` / `--ui-pad-sm` | 16px / 10px | 面板外/内边距 |
| 组间距 | 20px | 抽屉之间 |
| 行间距 | 8px | 字段之间 |

硬规则：组间距必须大于行间距。同组靠发丝线聚合，异组靠留白拉开。

## 4. 排版网格

### 4.1 字段行

```text
标签 58px | 控件 1fr | 读数 46px
```

- 三列基线对齐，读数右对齐、等宽。
- 标签超过 6 个汉字或 10 个字符时切换 `data-stacked="true"`：标签与读数在上，控件占满下一行。
- 同一抽屉内所有标签共用一条左边缘；控件起点一致。
- 每行顶部一条发丝线，第一行不画；不额外套边框。

### 4.2 抽屉

```text
30px 编号 | 1fr 标题 | auto 读数
```

- 收起时只留这一行，高度 38px。
- 展开时左侧出现 2px 琥珀竖条（`inset 2px 0 0`），标题不变色，编号变琥珀。
- 抽屉之间只有一条发丝线，不使用卡片。

## 5. 组件解剖

### 5.1 刻度滑杆 `gauge`

- 高 24px；轨道 1px，位于 `top:10px`。
- 已填充段 1px，琥珀，透明度 .4；拖拽时提到 1。
- 滑块是 2×14px 竖线，附一条 10px 横向游标，形成“十字测标”。
- 底部 11 根刻度线，每 5 根加高到 5px 并改用冷蓝。
- 交互：拖动、`←/→`、`↑/↓`、`PageUp/PageDown`、`Home/End`、双击复位。
- 必须带单位与小数位；`step` 决定小数位，`digits` 可覆盖。

### 5.2 档位 `bank`

- 连体单元格，外框 1px，单元格之间 1px 竖线。
- 选中：文字变琥珀 + 底部 2px 琥珀线；不加底色、不加圆角胶囊。
- 键盘：`←/→` 循环，`Home/End` 到两端；`role="radio"`。

### 5.3 机械开关 `key`

- 方形按键，左侧 5×5px LED，右侧等宽标签。
- 关闭：LED 空心，标签 muted；开启：LED 填充琥珀，标签 ink，边框琥珀，底色 `surface-2`。
- 标签只写 `ON/OFF` 或状态缩写，不写“开启/关闭”长句。

### 5.4 状态账本 `ledger`

- 底部 34px，五等分；每格左侧 1px 发丝线，第一格无。
- 标签冷蓝 9px，读数 10px 等宽。
- 读数溢出用省略号，不换行、不撑高。

### 5.5 命令索引 `Ctrl+K`

- 居中浮层，最大 680px，最高 70vh；实底 `surface`，1px 强边框，无投影。
- 搜索框通栏，44px；列表按组分段，组名冷蓝 9px。
- 行：左标签、右快捷键；选中行左侧 2px 琥珀条。
- 键盘：`↑↓` 选择、`Enter` 执行、`Esc` 关闭。

### 5.6 键位账本 `?`

- 两列分组表；行为按钮，可点击执行。
- 左列 58px 等宽键位，右列说明；分组之间用 10px 留白，不用卡片。

### 5.7 边轨与画布把手

- 仪表架收起后留 24px 边轨，竖排 `RACK` 与 `01–04`。
- 悬停 120ms 后浮出仪表架（`data-rack="peek"`），移开收回；点击编号固定展开。
- 顶栏与状态账本收起后，画布右侧保留 `TOP` / `HUD` 两个 28×24px 把手，保证任何状态都能恢复。

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| idle | 发丝线 + muted 标签 |
| hover | 边框提到 `line-strong`；文字不变色 |
| focus-visible | 1px 琥珀外环，偏移 2px |
| active | 琥珀文字 / LED / 底部 2px 线，三者只选其一 |
| disabled | 透明度 .38，禁止指针事件 |
| echo | 字段行底色 `surface-2` + 左侧 2px 琥珀条，600ms 后消失 |

布局三态：

1. 展开：顶栏 + 画布 + 316px 仪表架 + 34px 账本。
2. 面板收起：画布变宽，右侧 24px 边轨；`TOP` / `HUD` 把手仍在。
3. 沉浸：只剩画布、四角裁切标记与右侧边轨；`F` 或 `Esc` 退出并恢复进入前状态。

## 7. 可访问性

- 所有控件可 Tab 到达；滑杆 `role="slider"` + `aria-valuemin/max/now/text`。
- 档位 `role="radiogroup"`，按钮 `role="radio"` + `aria-checked`。
- 开关使用 `aria-pressed`。
- 浮层 `role="dialog"` + `aria-modal`，打开时焦点进搜索框，`Esc` 关闭。
- 焦点环只用 1px 实线，不依赖颜色单独传达状态（同时有文字/形状变化）。
- `prefers-reduced-motion` 下关闭过渡。

## 8. 扩展规则

- 新参数：在 `controlSchema` 增加一条 `gauge/bank/key`，不改 HTML。
- 新命令：`UI.registerCommand({ id, group, label, keys, run, detail })`；默认 `keys: []`，只进命令索引。
- 新面板：`UI.buildPanel(container, schema, store)`，复用同一套字段与抽屉。
- 新皮肤：只覆盖 `@layer tokens` 中的变量；组件形态差异放进 `@layer components`，不改 `base.css`。
- 新组件：`data-ui="name"` + `system.css` 中的独立块 + 可选 `UI.register`，不往现有组件里塞特例。

## 9. 复用到实验 1、2

- 实验 1（几何/变换）：把 `01 LIGHT` 换成 `01 TRANSFORM`，字段改为 `tx/ty/tz/rx/ry/rz/scale`，仍然三列网格。
- 实验 2（模型/视图）：`02 MATERIAL` 改为 `02 PROJECTION`，`03 EFFECTS` 改为 `03 CLIPPING`。
- 共用 `base.css` 与 `system.js`，只写各自的 `page.css` 与 `commands.js`，不复制组件样式。
- 若实验 1、2 需要浅色底，只替换 `@layer tokens` 的 `--ui-bg/surface/ink/line`，其余不变。

## 10. 验收清单

- [ ] 面板字段严格三列，长标签已上下排。
- [ ] 组间距 20px > 行间距 8px。
- [ ] 每组只有一条发丝线，无嵌套边框。
- [ ] 全页只有一种强调色；冷蓝只用于状态。
- [ ] 三种字号角色同时存在。
- [ ] 没有卡片、胶囊、渐变、投影、毛玻璃、emoji。
- [ ] 三态收起可用，`Esc` 能退出沉浸并恢复。
- [ ] `Ctrl+K`、`?`、`P`、`F`、`Space` 均可用，且无键位冲突。
- [ ] 1280px 与 900px 宽度下无重叠、无横向滚动。
